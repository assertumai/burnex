burnex itself is developed with its own pipeline: the [self-improve](https://github.com/assertumai/burnex/blob/main/.burnex/pipelines/self-improve.yml) loop takes an improvement from the queue, writes a spec for it, implements it until the build is green, reviews it in a separate session, and commits.
