Сам burnex развивается собственным пайплайном: петля [self-improve](https://github.com/assertumai/burnex/blob/main/.burnex/pipelines/self-improve.yml) берёт улучшение из очереди, заводит под него спецификацию, реализует до зелёной сборки, ревьюит отдельной сессией и коммитит.
