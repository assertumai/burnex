Шаг считается успешным, только если прошли его проверки — **`expect`**. Проверки объявляет автор пайплайна; движок вычисляет их после каждой попытки, и непрошедшая проверка — отказ шага.

```yaml
- id: implement
  agent: claude
  prompt: file:./prompts/implement.md
  output_schema: ./schemas/implement.json
  expect:
    - schema: ./schemas/implement.json        # вывод по схеме
    - changed_only: ["src/**", "test/**"]     # правки не вышли за границы
    - cmd: npm test                           # тесты зелёные
```

## Предикаты

| Предикат | Что проверяет |
|---|---|
| `exit_code: 0` | код возврата |
| `schema: <путь>` | структурированный вывод соответствует JSON Schema |
| `changed_only: [glob]` | изменённые файлы не вышли за шаблоны |
| `cmd: "..."` | команда завершилась нулём |
| `script: <путь>` | проверка-скрипт на любом языке завершилась нулём |
| `file_exists`, `matches`, `not_matches` | файл создан, текст результата содержит или не содержит |
| `judge: "..."` | оценка агентом-судьёй |

Ключи закрыты: опечатка `exit_cod` — ошибка разбора, а не тихо пропущенная проверка. Плагины добавляют свои предикаты.

## Схема вывода

`output_schema` уходит агенту штатным механизмом структурированного вывода его CLI (Claude, Codex). У бэкенда без такого механизма (Cursor, Copilot) схема идёт в промпт, а движок берёт последний JSON-блок ответа и проверяет его сам; ответ мимо схемы — повтор с ошибкой схемы.

## Жёсткие проверки и судья

Жёсткими гейтами стоит делать проверки дешевле и надёжнее самой работы: код возврата, схему, тесты. Судья — отдельный агентский вызов в своей сессии, он видит только вывод шага и по умолчанию **совещательный** (`hard: false`): его вердикт пишется в журнал, но шаг не роняет.

```yaml
expect:
  - judge: "План покрывает все требования из спеки"
    hard: true
```

## Чего контракт не делает

- Не проверяет, что попытка отличается от предыдущей: повторы ограничены только числом попыток и бюджетом.
- `changed_only` проверяет границы, а не факт работы: шаг, не изменивший ничего, его пройдёт. Держите рядом проверку результата.
