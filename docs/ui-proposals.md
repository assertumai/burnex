## Что есть сейчас

Экраны: Runs, Run, Pipelines, Widgets, Backlog, Scrum, Usage, Cleanup, Agents,
Settings, Routes, Decisions, Proposals. Меню собирается из `src/builtin/routes.yml`
по группам `work`, `system`, `extend`.

## 1. Слить Settings и Agents

Settings (≈300 строк) содержит агента и модель по умолчанию и список бэкендов.
Agents (≈560 строк) — уровни (tier), эскалация и бэкенды. Это одна тема: кто и
чем работает. `agent_policy` при этом размазан по `PipelineAgents` и `Pipelines`.

Предложение — один экран **Agents** с вкладками:

- **Default** — агент и модель по умолчанию (из Settings);
- **Backends** — список бэкендов (из Settings), статус, подключение новых;
- **Tiers** — то, что сейчас на Agents;
- **Policy** — `agent_policy` и выбор агента на пайплайн и на шаг.

`/settings` остаётся редиректом на `/agents`, в меню один пункт. Settings можно
сохранить как корень общих настроек, если туда переедут расписание и автозапуск
(см. п. 2).

Решено (`ui-agents-settings-merge`): вкладка — параметр пути `/agents/:tab?`,
`/settings` — строка маршрута с целью `screen-agents`, не редирект; строка
`screen-settings` демона удалена, `/api/settings` принадлежит `screen-agents`.

## 2. Возможности без UI

| Возможность | Что нужно в UI |
|---|---|
| Секреты по имени (провайдеры, `keychain`) | вкладка или экран: провайдеры, имена секретов, статус; значения не показывать |
| Расписание: догон, `keep_awake`, `require_network` | просмотр расписания; следов догона в `Runs.tsx` нет |
| Автозапуск launchd (`up --install`) | переключатель «запускать при входе» и статус |
| `stepcast update`, `install.sh` | версия, доступное обновление, кнопка «Обновить» |
| Пакеты (`packages-directory-layer`) | каталог пакетов, состав, ошибки слоя; сейчас они только в предупреждении на «Маршруты» |
| Shadow-режим | запуск «насухо» и пометка таких прогонов в списке |
| `run --env KEY=VALUE` | поля env в диалоге ручного запуска |
| Бэкенды Cursor и Copilot | в списке есть, когда объявлены; нет действия «подключить», как у Codex |
| `loops` на работе | проходы группы на графе прогона; `attempts` в `RunDetail`/`StepOutput` уже есть |
| Очередь: `claimed_by`, lock-файл | кто держит пункт и блокировка; в `Backlog.tsx` нет |
| `backlog add` / `backlog show` | уже есть на «Scrum» через `POST /api/backlog/item` |

Частично есть: цена `reported`/`catalog` (Usage, Runs, RunDetail), `needs`
(Scrum, граф), кнопка Resume (RunDetail), `attempts`.

## 3. Что добавить в UI в целом

- **Группа «Конфигурация»** в меню `system`: Agents, Секреты, Расписание,
  Пакеты, Автозапуск вместо россыпи экранов.
- **Здоровье системы**: демон, версия, авторизация бэкендов (истёкший OAuth уже
  останавливал петлю), предупреждение «цена модели неизвестна, `budget.cost` не
  действует».
- **Диалог запуска прогона**: вход, env, shadow, выбор агента в одной форме.
- **Очередь**: владелец пункта, блокировка, добавление пункта из UI.

## Порядок

1. Слияние Settings и Agents — недорого, почти перестановка. **В работе.**

3. Здоровье системы и диалог запуска.
4. Пакеты, обновление, автозапуск.
