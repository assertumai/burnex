## ADDED Requirements

### Requirement: Срок сужает исход в снятии записей командой

`stepcast gc --stats` SHALL применять `--older-than` к признаку `--failed` по «и»: при обоих ключах MUST сниматься только записи отказавших прогонов старше срока. Один `--older-than` MUST снимать все записи старше срока, один `--failed` — все записи отказавших прогонов. Отбор записей командой MUST совпадать с отбором витрины при тех же условиях.

#### Scenario: Отказавшие старше срока

- **WHEN** вызвана `stepcast gc --stats --failed --older-than 2d`, а в хранилище есть запись отказавшего вчера прогона, запись отказавшего десять дней назад и запись успешного десять дней назад
- **THEN** снята только запись отказавшего десять дней назад

#### Scenario: Срок без исхода

- **WHEN** вызвана `stepcast gc --stats --older-than 2d`
- **THEN** сняты все записи старше двух дней независимо от исхода
