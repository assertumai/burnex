## 3. Признак адаптера и предупреждение на старте

- [x] 3.1 `reportsCost?: boolean` в `BackendCapabilities`. `true` у Claude
      (`src/parts/backends/claude/adapter.ts`), `false` у Codex
      (`src/parts/backends/codex/adapter.ts`), настраиваемый у поддельного
      бэкенда (`src/parts/pipeline/backend/fake.ts`), по умолчанию `true`,
      чтобы существующие тесты не меняли поведения.
- [x] 3.2 Проверка на старте в `src/parts/pipeline/run/runner.ts`. Только
      при `anyCostBudgetDeclared`. Обход агентских шагов и судей их `expect`
      с раскрытой моделью и бэкендом. Вызов без цены — `reportsCost !== true`
      и модель не объявлена или её нет в каталоге.
- [x] 3.3 Событие `budget.cost_unpriced` (job, step, backend, model — если
      объявлена) в схеме журнала. Предупреждение в вывод прогона с работой,
      шагом, бэкендом и моделью («модель по умолчанию CLI», если не
      объявлена) и словами, что `budget.cost` этот вызов не проверяет.
- [x] 3.4 Тесты. Предупреждение и событие для модели вне каталога и для
      необъявленной модели. Ничего для бэкенда с `reportsCost: true`, ничего
      без `budget.cost`. Адаптер без признака получает предупреждение.
      Прогон не останавливается. Сообщённая вопреки признаку цена
      учитывается как `reported`.
