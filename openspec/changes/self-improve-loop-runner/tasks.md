## 3. Тест скрипта

- [x] 3.1 Тест на одноразовом git-репозитории (во временном каталоге) с собственным `package.json` без зависимостей: `build` пишет поддельный `dist/src/bin.js`, а тот по сценарию коммитит в ветку или нет и выходит нужным кодом; скрипт копируется в `scripts/` этого репозитория и запускается оттуда
- [x] 3.2 Сценарии: остановка по `MAX_RUNS` (поддельный движок коммитит каждый раз, `MAX_RUNS=2` → две итерации, код `0`); остановка по «ничего не закоммитил» (код `0` при успешном прогоне, код прогона при ненулевом); свело, но прогон красный → следующая итерация; упавшая сборка → код `1` без запуска прогона; отделённый HEAD → код `2`
- [x] 3.3 Сценарии сборки: `npm ci` не повторяется при неизменном lockfile (счётчик через `preinstall`/`postinstall` поддельного пакета либо отметку в worktree) и повторяется после коммита, меняющего lockfile; движок собран из коммита — незакоммиченная правка поддельного `bin.js` в копии в итерацию не попадает
- [x] 3.4 Грязная копия: незакоммиченный файл в копии не мешает итерации и не останавливает петлю
- [x] 3.5 Тест не зависит от сети: пакет без зависимостей, `npm ci` с пустым lockfile
