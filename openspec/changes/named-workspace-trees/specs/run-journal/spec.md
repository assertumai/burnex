## ADDED Requirements

### Requirement: Запись работы называет её дерево и засев

Запись работы в состоянии прогона SHALL нести поле `tree` — идентификатор дерева, в котором работа исполнялась, либо `own` для личного дерева или каталога при `scope: job`. Работа, для которой заведён каталог с источником, MUST нести `seed` с полями `from` (работа-источник или `none`), `by` (`copy` — перенесена рабочая директория источника, `anchor` — засев якорем) и `reason` при `by: anchor`. Работа, продолжающая уже заведённое дерево, MUST нести `continued: true`. Записи прежнего формата без `tree` MUST читаться без ошибки.

#### Scenario: Работа дерева по умолчанию

- **WHEN** работа исполнилась в дереве по умолчанию `main` после другой его работы
- **THEN** её запись несёт `tree: main` и `continued: true`

#### Scenario: Голова именованного дерева

- **WHEN** голова дерева `b` получила рабочую директорию работы `build`
- **THEN** её запись несёт `tree: b` и `seed: { from: build, by: copy }`

#### Scenario: Прежняя запись

- **WHEN** читается состояние прогона, записанное до этого изменения
- **THEN** записи работ без `tree` читаются, а их каталоги берутся из записанного пути
