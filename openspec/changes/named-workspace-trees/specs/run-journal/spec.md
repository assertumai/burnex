## ADDED Requirements

### Requirement: Запись работы называет её дерево

Запись работы в состоянии прогона SHALL нести поле `tree` — идентификатор дерева, в котором работа исполнялась, либо `own` для личного дерева. Голова дерева, отпочкованного от работы, MUST нести `inherited_from` с идентификатором источника. Работа, исполнявшаяся в уже заведённом дереве, MUST нести `continued: true`. Записи прежнего формата без `tree` MUST читаться без ошибки.

#### Scenario: Работа дерева по умолчанию

- **WHEN** работа исполнилась в дереве по умолчанию `main` после другой его работы
- **THEN** её запись несёт `tree: main` и `continued: true`

#### Scenario: Голова именованного дерева

- **WHEN** голова дерева `b` отпочковалась от работы `build`
- **THEN** её запись несёт `tree: b` и `inherited_from: build`

#### Scenario: Прежняя запись

- **WHEN** читается состояние прогона, записанное до этого изменения
- **THEN** записи работ без `tree` читаются, а их каталоги берутся из записанного пути
