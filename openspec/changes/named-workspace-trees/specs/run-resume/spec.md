## ADDED Requirements

### Requirement: Возобновление восстанавливает каждое дерево

Возобновление SHALL восстанавливать рабочие каталоги по деревьям. Для каждого дерева MUST браться его каталог из исходного прогона, а если его нет — каталог MUST заводиться заново от источника дерева. Затем каталог MUST восстанавливаться по якорю последнего переиспользованного шага этого дерева. Восстанавливается только отслеживаемое состояние: неотслеживаемое и игнорируемое содержимое, оставленное работами исходного прогона после точки возобновления, MUST NOT удаляться. Работа, чей шаг продолжает свою сессию в перенятом каталоге, MUST исключаться из восстановления, как и прежде.

#### Scenario: Возобновление в общем дереве

- **WHEN** при `scope: run` три работы шли в дереве по умолчанию, и возобновление начинает переисполнение с первой из них
- **THEN** каталог дерева перенят из исходного прогона и приведён к якорю перед первым переисполняемым шагом
- **AND** игнорируемые каталоги, созданные второй и третьей работами, остаются на месте

#### Scenario: Каталог дерева удалён

- **WHEN** каталог дерева исходного прогона удалён, а якоря доступны
- **THEN** каталог заводится заново, приводится к якорю последнего переиспользованного шага, и возобновление продолжается
