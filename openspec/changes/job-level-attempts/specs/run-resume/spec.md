## ADDED Requirements

### Requirement: Работа с попытками возобновляется целиком

Для работы с `attempts.max` больше 1 единицей повтора при возобновлении SHALL быть работа целиком: если хотя бы один её шаг переисполняется, переисполняются все её шаги.
Объяснение MUST называть попытки работы причиной переисполнения шагов с
валидным ключом. Указание шага такой работы в `--from` MUST отклоняться с
объяснением и указанием работы как ближайшей допустимой точки. Продолжение
оборванной сессии MUST подчиняться тому же правилу «всё или ничего», что при
`session: shared`. Счёт попыток работы в новом прогоне MUST начинаться с 1.

#### Scenario: Невалидный второй шаг переисполняет работу целиком

- **WHEN** работа объявляет `attempts: { max: 2 }` и `session: per_step`, а её второй шаг признан невалидным
- **THEN** переисполняются все шаги этой работы, включая первый
- **AND** объяснение называет попытки работы причиной переисполнения первого шага

#### Scenario: Шаг указан для работы с попытками

- **WHEN** возобновление вызвано с `--from impl/review`, а работа `impl` объявляет `attempts: { max: 2 }`
- **THEN** команда завершается ошибкой и называет `impl` как допустимую точку возобновления

#### Scenario: Работа целиком переиспользуется

- **WHEN** работа с `attempts: { max: 2 }` прошла в исходном прогоне со второй попытки, и все её шаги валидны
- **THEN** шаги переиспользуются по записям последней попытки, а дерево восстанавливается по их якорям
