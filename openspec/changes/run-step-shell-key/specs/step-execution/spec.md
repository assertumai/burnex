## ADDED Requirements

### Requirement: Строковый run исполняется объявленной оболочкой
Шаг `run` со строкой и действующей `shell` SHALL исполнять команду как argv `[...shell, command]` без оболочки платформы; без действующей `shell` строка MUST исполняться, как прежде, через `sh -c` на POSIX-системах и `cmd.exe /c` на Windows. Шаг `run` в списочной форме MUST исполняться без оболочки независимо от `shell`.

#### Scenario: Объявленная оболочка
- **WHEN** действующая `shell` равна `[bash, -lc]`, а шаг объявляет `run: "echo $0"`
- **THEN** процесс запускается как `bash -lc "echo $0"`

#### Scenario: Оболочка не объявлена
- **WHEN** ни один уровень не объявил `shell`, а шаг объявляет `run: "npm test | tee out.txt"`
- **THEN** команда исполняется через оболочку платформы, как прежде

#### Scenario: Списочная форма
- **WHEN** действующая `shell` объявлена, а шаг объявляет `run: [npm, test]`
- **THEN** процесс запускается без оболочки, а аргументы передаются как есть
