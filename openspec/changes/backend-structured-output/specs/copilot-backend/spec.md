## ADDED Requirements

### Requirement: Copilot отвечает по схеме через итоговый текст

Адаптер Copilot SHALL объявлять `schemaFromText: true`, оставляя `structuredOutput` выключенным: ни CLI, ни ACP-сервер, ни SDK Copilot схемы не принимают, а с `-s` stdout несёт один текст ответа, который движок склеивает из строк. Шаг с `output_schema`, участник шага `review` и судья на `copilot` MUST исполняться движковой схемой по итоговому тексту и MUST NOT отклоняться до старта за отсутствие схемы.

#### Scenario: Ревьюер на Copilot

- **WHEN** стратегия объявляет ревьюера на `copilot`, а его ответ заканчивается блоком ```` ```json ```` с находками по схеме
- **THEN** запуск `copilot` не несёт флага схемы, промпт несёт схему находок, а находки ревьюера взяты из блока
