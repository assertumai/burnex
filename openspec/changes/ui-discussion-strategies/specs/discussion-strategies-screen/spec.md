## ADDED Requirements

### Requirement: API стратегий обсуждения

Демон SHALL отдавать `GET /api/discussion-strategies` — стратегии обсуждения проектного слоя (`.burnex/discussion-strategies/`) и домашнего (`~/.burnex/discussion-strategies/`) с текстом файла, документом либо отказом разбора движка с путём ключа, признаком перекрытия проектной стратегией и шагами `discuss:` пайплайнов проекта, разрешающимися в этот файл. `PUT` MUST записывать стратегию в файл её слоя правкой YAML-документа, проверяя результат тем же разбором, что у движка, до подмены файла; отказ разбора MUST давать 400 с текстом и путём ключа, а файл MUST оставаться прежним. `DELETE` MUST удалять файл слоя.

#### Scenario: Список с использованием

- **WHEN** проектная стратегия `panel` используется шагом `discuss: panel`, а в домашнем слое есть `panel` и `solo`
- **THEN** ответ содержит обе `panel` (домашняя — перекрытая) и `solo`, у проектной `panel` — шаг в использовании

#### Scenario: Отказ записи у поля

- **WHEN** сохраняется стратегия с участником `id: author`
- **THEN** ответ 400 с путём `participants.0.id`, файл не изменён

### Requirement: Экран Discussion strategies

Витрина SHALL показывать экран «Discussion strategies» по адресу `/discussion-strategies/:name?` в группе `config` меню: список стратегий обоих слоёв с меткой слоя и редактор выбранной — раунды защиты от 1 до 5 со схемой хода, автор и агрегатор (агент, модель или уровень, `effort`, промпт), участники (`id`, агент, модель или уровень, `effort`, `focus`), локальные профили и список использующих шагов. Перекрытая стратегия MUST быть только для чтения; файл, который не разбирается, MUST показываться текстом с отказом. Новая стратегия MUST создаваться в выбранном слое; отказ демона MUST показываться у поля по пути ключа.

#### Scenario: Правка раундов

- **WHEN** пользователь ставит 3 раунда и сохраняет
- **THEN** в файл пишется `rounds: 3`, прочие ключи и комментарии на месте

#### Scenario: Схема хода

- **WHEN** открыта стратегия с `rounds: 2`
- **THEN** экран показывает этапы предложений, черновика, возражений, защиты не более 2 раундов и документа
