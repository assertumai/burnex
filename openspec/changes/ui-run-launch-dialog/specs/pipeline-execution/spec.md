## ADDED Requirements

### Requirement: Агент по умолчанию на один прогон
`stepcast run` SHALL принимать флаг `--agent <имя>`, который на этот прогон заменяет значение `defaults.agent` слоем флага поверх файлов конфигурации. Выбор MUST действовать там же, где действует `defaults.agent` из файла конфигурации, и по тому же порядку слоёв: агент, названный шагом или работой документа либо записью `pipeline_agents`/`step_agents`, MUST оставаться прежним при любой `agent_policy`; агент корня документа MUST оставаться прежним при `agent_policy: force` и уступать выбору при `agent_policy: fallback`, как уступает `defaults.agent`. Имя, не известное конфигурации как бэкенд, MUST отклоняться ошибкой конфигурации до создания каталога прогона, в том числе при `--dry-run`, с перечнем известных имён. Без флага прогон MUST разрешать агентов как прежде.

#### Scenario: Шаг без явного агента
- **WHEN** `defaults.agent` равен `claude`, шаг документа агента не называет, а прогон запущен с `--agent codex`
- **THEN** шаг исполняется агентом `codex`

#### Scenario: Шаг с явным агентом документа
- **WHEN** шаг документа объявляет `agent: claude`, а прогон запущен с `--agent codex`
- **THEN** шаг исполняется агентом `claude`

#### Scenario: Агент корня документа при agent_policy: force
- **WHEN** документ объявляет `agent: claude` на корне, `agent_policy` равен `force`, а прогон запущен с `--agent codex`
- **THEN** шаги, не названные шагом или работой, исполняются агентом `claude`

#### Scenario: Агент корня документа при agent_policy: fallback
- **WHEN** документ объявляет `agent: claude` на корне, `agent_policy` равен `fallback`, а прогон запущен с `--agent codex`
- **THEN** шаги, не названные шагом или работой, исполняются агентом `codex`, а шаг с собственным `agent: claude` — агентом `claude`

#### Scenario: Запись пользователя для пайплайна
- **WHEN** `pipeline_agents` для пайплайна называет `agent: claude`, а прогон запущен с `--agent codex`
- **THEN** агентские шаги пайплайна, не названные документом, исполняются агентом `claude`

#### Scenario: Неизвестный агент
- **WHEN** прогон запущен с `--agent nope`, а бэкенда `nope` в конфигурации нет
- **THEN** команда завершается ошибкой конфигурации с перечнем известных агентов, каталог прогона не создаётся

#### Scenario: Прогон без флага
- **WHEN** прогон запущен без `--agent`
- **THEN** агенты шагов те же, что показывает `stepcast config --pipeline` для этого пайплайна
