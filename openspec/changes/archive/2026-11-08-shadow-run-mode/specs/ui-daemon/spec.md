## ADDED Requirements

### Requirement: Запуск прогона принимает shadow-режим
Маршрут `POST /api/run` SHALL принимать необязательное булево поле `shadow` и при значении `true` передавать дочернему `stepcast run` флаг `--shadow`. Значение не булева типа MUST отклоняться ответом 400; запрос без поля или с `shadow: false` MUST запускать прогон как прежде.

#### Scenario: Shadow-запуск через API
- **WHEN** приходит запрос с `shadow: true` для известного проекта и пайплайна
- **THEN** демон порождает `stepcast run` с `--shadow` и отвечает 202

#### Scenario: Не булево значение
- **WHEN** приходит запрос с `shadow: "yes"`
- **THEN** ответ — 400, процесс не порождается

#### Scenario: Запрос без поля
- **WHEN** приходит запрос без поля `shadow`
- **THEN** команда запускается без `--shadow`, как прежде
