## ADDED Requirements

### Requirement: Возобновление наследует переопределения env
Возобновление SHALL брать переопределения env из `env_overrides` манифеста исходного прогона, применять их к новому прогону и записывать в его `run.json`. Манифест без `env_overrides` MUST читаться как прогон без переопределений.

#### Scenario: Переопределение пережило возобновление
- **WHEN** прогон запущен с `--env MODE=slow`, упал, и вызван `stepcast resume`
- **THEN** шаги возобновлённого прогона видят `MODE=slow`, а его `run.json` содержит то же `env_overrides`

#### Scenario: Прогон прежней версии
- **WHEN** возобновляется прогон, чей `run.json` не содержит `env_overrides`
- **THEN** возобновление проходит без переопределений и без ошибки чтения манифеста
