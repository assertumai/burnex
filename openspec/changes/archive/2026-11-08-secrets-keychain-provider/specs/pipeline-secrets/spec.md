## ADDED Requirements

### Requirement: Встроенный провайдер секретов keychain

Система SHALL регистрировать встроенный провайдер секретов `keychain`, значение которого — вывод `security find-generic-password -a <account> -s <service> -w` без завершающего перевода строки.
Параметры `service` и `account` MUST быть обязательными непустыми строками,
прочие параметры MUST отклоняться схемой провайдера. Команда MUST запускаться
без оболочки и MUST прерываться по истечении 5 секунд или по отмене прогона.
Не на macOS провайдер MUST отказывать, не запуская команды. Отсутствующая
запись, таймаут и ненулевой код возврата MUST давать отказ разрешения с
`service` и `account`, а сообщение отказа MUST NOT содержать вывода команды.
Провайдер MUST регистрироваться тем же путём, что `env-file`.

#### Scenario: Значение из связки ключей

- **WHEN** секрет объявлен с `provider: keychain`, `service: github.com`, `account: alice`, а команда печатает значение и перевод строки
- **THEN** шаг, назвавший секрет, получает значение без завершающего перевода строки

#### Scenario: Не macOS

- **WHEN** прогон с названным шагом секретом `provider: keychain` запущен не на macOS
- **THEN** запуск отклонён до создания каталога прогона с объяснением, что провайдер доступен только на macOS
- **AND** команда `security` не запускалась

#### Scenario: Записи нет

- **WHEN** команда завершилась кодом 44
- **THEN** запуск отклонён с именем секрета, `service` и `account`, каталог прогона не создан

#### Scenario: Команда не отвечает

- **WHEN** команда не завершилась за 5 секунд
- **THEN** процесс команды остановлен, а запуск отклонён с указанием таймаута и без каталога прогона

#### Scenario: Без account

- **WHEN** секрет с `provider: keychain` не указывает `account`
- **THEN** `stepcast lint` и запуск отклоняют объявление с указанием параметра

#### Scenario: Линт не проверяет платформу

- **WHEN** документ с секретом `provider: keychain` проверяется `stepcast lint` не на macOS
- **THEN** линт не сообщает об ошибке платформы
