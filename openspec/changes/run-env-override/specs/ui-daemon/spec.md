## ADDED Requirements

### Requirement: Запуск прогона принимает переопределения env
Маршрут `POST /api/run` SHALL принимать необязательное поле `env` — объект «имя переменной — однострочная строка» — и передавать каждую пару дочернему `stepcast run` ключом `--env`. Имя вне формы идентификатора и многострочное значение MUST отклоняться ответом 400; запрос без `env` MUST вести себя как прежде.

#### Scenario: Поле env доехало до команды
- **WHEN** приходит запрос с `env: { MODE: "slow" }` для известного проекта и пайплайна
- **THEN** демон порождает `stepcast run` с `--env MODE=slow` и отвечает 202

#### Scenario: Многострочное значение
- **WHEN** значение в `env` содержит перевод строки
- **THEN** ответ — 400, процесс не порождается

#### Scenario: Запрос без env
- **WHEN** приходит запрос без поля `env`
- **THEN** команда запускается без ключей `--env`, как прежде
