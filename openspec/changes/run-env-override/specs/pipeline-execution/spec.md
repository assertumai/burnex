## ADDED Requirements

### Requirement: Прогон переопределяет объявленный env флагом
Команда `stepcast run` SHALL принимать повторяемый флаг `--env KEY=VALUE`, меняющий на один прогон значение ключа, объявленного в верхнеуровневом `env:` пайплайна. Ключ, не объявленный там, и значение с переводом строки MUST отклоняться до запуска ошибкой конфигурации. Значение MUST браться буквально: подстановки `${...}` в нём не раскрываются. Файл пайплайна и его lock-хеш MUST оставаться прежними.

#### Scenario: Объявленный ключ переопределён
- **WHEN** пайплайн объявляет `env: { MODE: fast }`, а прогон запущен с `--env MODE=slow`
- **THEN** шаги видят `MODE=slow`, а прогон без флага видит `MODE=fast`

#### Scenario: Необъявленный ключ
- **WHEN** прогон запущен с `--env OTHER=1`, а `OTHER` не объявлен в `env:` пайплайна
- **THEN** команда завершается ошибкой конфигурации, называющей ключ, и прогон не создаётся

#### Scenario: Многострочное значение
- **WHEN** значение `--env` содержит перевод строки
- **THEN** команда завершается ошибкой конфигурации, и прогон не создаётся

#### Scenario: Подстановка не раскрывается
- **WHEN** прогон запущен с `--env MODE='${inputs.x}'`
- **THEN** шаги видят в `MODE` текст `${inputs.x}` без раскрытия

#### Scenario: Переопределения записаны в манифест
- **WHEN** прогон запущен с двумя флагами `--env`
- **THEN** `run.json` содержит `env_overrides` с обоими ключами и значениями
